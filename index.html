Vertical, valiente, intenso, adaptable

Una forma
de competir

El estilo de Rubén Albés se basa en la valentía y la verticalidad. Sus equipos defienden con un bloque organizado que se transforma según el contexto, y en ataque la consigna es clara: jugar en largo para saltar líneas de presión y transitar rápido hacia portería. Se define como un entrenador plástico, que adapta el modelo a los jugadores disponibles antes que imponer un sistema rígido, buscando siempre que el equipo fluya de forma natural. El resultado es un fútbol directo, intenso y difícil de superar, orientado siempre a hacer daño al rival.

Valentía Táctica

Presión alta y línea defensiva adelantada. El equipo nunca cede terreno sin disputarlo.

Identidad Colectiva

El grupo primero. El sistema existe para liberar al jugador, no para limitarlo.

Plasticidad

4-3-3, 5-2-3, 4-1-4-1. El sistema cambia con el partido. La actitud, nunca.
